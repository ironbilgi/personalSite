Features

Here are some of the features of the extension:

Live 3D surface plotting

Type any function f(x, y) and see it rendered as an interactive 3D surface instantly. Rotate, zoom, and pan to view it from any angle, powered by Plotly.js.

Gradient vector visualization

Click a point on the surface and see the gradient vector at that point, computed via finite differences — makes "steepest ascent" visible instead of just a formula.

Level curves / contour view

Toggle a 2D contour projection alongside the 3D view to connect level curves to the actual surface they slice.

No install required

Runs as a plain web page (with an optional installable PWA mode), so it works even on school Chromebooks where extensions are blocked.

Instant function parsing

Powered by math.js, so it accepts natural notation like x^2 + y^2 or sin(x)*cos(y) without special syntax.

Lightweight and fast

No backend, no account, no loading screen — everything runs client-side in the browser.
